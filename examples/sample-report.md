# Sample PR Sentinel Rules

## Security

### SEC-001 — Hardcoded Token

ID: SEC-001
Category: Security
Severity: CRITICAL
Description: A possible hardcoded token was detected.
Suggestion: Move the token into an environment variable.
Pattern: token=

## Quality

### CODE-001 — TODO

ID: CODE-001
Category: Quality
Severity: LOW
Description: TODO marker detected.
Suggestion: Resolve the TODO.
Pattern: TODO
